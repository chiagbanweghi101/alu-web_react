# React Props

Holberton School project covering React components, props, PropTypes, shapes, and testing with Jest/Enzyme.

## Tasks

- **task_0** — Split App into Header, Footer, and Login components
- **task_1** — Write tests for each component
- **task_2** — Split Notifications with NotificationItem
- **task_3** — React DevTools screenshots
- **task_4** — PropTypes, CourseList, displayDrawer, isLoggedIn
- **task_5** — Shapes, loops, and keys

## How to run

```bash
cd task_N/dashboard
npm install
npm start
npm test
```
