# React Inline Styling

Holberton School project covering inline styles, Aphrodite, conditional styles, responsive design, and animations.

## Tasks

- **task_0** — Inline styling for CourseListRow
- **task_1** — Aphrodite stylesheet migration
- **task_2** — Conditionally applying Aphrodite styles
- **task_3** — Responsive design under 900px
- **task_4** — Notifications menu animations

## How to run

```bash
cd task_N/dashboard
npm install
npm start
npm test
```
