# Webpack

Holberton School Webpack project covering basic setup, configuration, loaders, plugins, code splitting, and the development server.

## Tasks

- **task_0** — Basic Webpack install (no config), jQuery DOM content
- **task_1** — Webpack config, production build, Lodash debounce
- **task_2** — CSS & image loaders with image optimization
- **task_3** — Dev server, modules, HtmlWebpackPlugin, CleanWebpackPlugin, splitChunks

## How to run

```bash
# task_0
cd task_0 && npm install && npx webpack

# task_1
cd task_1 && npm install && npm run build

# task_2
cd task_2 && npm install && npm run build

# task_3
cd task_3 && npm install && npm run build
# or: npm run start-dev
```
